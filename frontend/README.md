# Cliente React

Interfaz de Control de Stock para la API FastAPI/MySQL del proyecto.
Consultar el [README principal](../README.md) para configurar la base de datos y el backend.

```sh
npm ci
npm run dev
npm run lint
npm run build
```

Vite redirige `/api` a `http://localhost:3000`. La compilación `dist/` puede servirse desde FastAPI.
